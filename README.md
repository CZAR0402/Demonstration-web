# Fivopay Sales Engine — Client (Frontend)

React + Vite frontend web application for Fivopay Sales Engine & Product Features Platform.

## Features
- **CRM Workspace**: Leads Database, Sales BDE Team Management, CRM Pipeline, SES Campaigns.
- **Developer REST API Showcase**: Razorpay/Stripe style tabbed REST API reference for all product features.

## Quick Start
```bash
# Install frontend dependencies
npm install

# Start Vite local development server
npm run dev

# Build production bundle
npm run build
```
